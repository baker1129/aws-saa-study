# 試験ガイド概要（SAA-C03）

## 試験で問われること

SAAは「AWSサービスを知っているか」ではなく、**「このビジネス要件を満たす設計を選べるか」** を問う。

問題文には必ず「要件」が書かれている。
- 「コストを最小にしたい」
- 「99.99%の可用性が必要」
- 「オンプレミスとAWSを安全に接続したい」

その要件に対して、**最も適切な設計を4択から選ぶ**。

---

## 4つのドメインと出題比率

```
Domain 1: セキュアなアーキテクチャの設計      ████████████  30%
Domain 2: 回復性の高いアーキテクチャの設計    ██████████    26%
Domain 3: 高パフォーマンスなアーキテクチャ    █████████     24%
Domain 4: コスト最適化されたアーキテクチャ    ████████      20%
```

## 問題を解くときの思考フロー

```
問題文を読む
    ↓
①「何が要件か」を特定する
  （高可用性？コスト削減？セキュリティ？パフォーマンス？）
    ↓
②「何が制約か」を確認する
  （サーバーレス必須？オンプレ接続あり？既存DBを活かす？）
    ↓
③ 要件・制約に合う設計を選ぶ
  （似たサービスがあれば「なぜこちらか」を理由で判断）
    ↓
④ 消去法で絞る
  （明らかに要件を満たさないものを除外）
```

この流れが自然にできるようになることが、Phase 3の最終ゴール。
