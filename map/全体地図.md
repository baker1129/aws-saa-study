# 全体地図 — SAAで問われる「問い」の一覧

SAAの試験問題は、必ずこの問いのどれかに答えを求めている。  
迷ったとき、まずここに戻る。

---

## 1. 何で動かすか（計算リソース）

| 問い | 答えの方向 |
|------|-----------|
| サーバーを自分で管理したい | EC2 |
| コードだけ動かせればいい（サーバー不要） | Lambda |
| コンテナを使いたい（管理あり） | ECS on EC2 |
| コンテナを使いたい（管理なし） | Fargate |
| 大量のバッチ処理を効率よく | Batch |

詳細 → `計算リソース.md`

---

## 2. どこに保存するか（ストレージ・DB）

| 問い | 答えの方向 |
|------|-----------|
| ファイルを大量に安く保存 | S3 |
| EC2から直接マウントするディスク | EBS |
| 複数のEC2から同時にマウント | EFS |
| 構造化データ（行・列のテーブル） | RDS / Aurora |
| 大量アクセス・スキーマレス | DynamoDB |
| 分析・集計クエリ（大量データ） | Redshift |
| キャッシュ（高速・一時的） | ElastiCache |

詳細 → `ストレージ.md`, `データベース.md`

---

## 3. どう繋ぐか（ネットワーク）

| 問い | 答えの方向 |
|------|-----------|
| ネットワークを論理的に分離したい | VPC / サブネット |
| 外からのHTTPを複数サーバーに振り分け | ALB |
| TCPレベルで高速に振り分け | NLB |
| 静的コンテンツを世界中に速く配信 | CloudFront |
| ドメイン名でルーティング | Route 53 |
| オンプレミスとAWSを繋ぐ（VPN） | Site-to-Site VPN |
| オンプレミスとAWSを繋ぐ（専用線） | Direct Connect |

詳細 → `ネットワーク.md`

---

## 4. 誰が何をできるか（セキュリティ・アクセス管理）

| 問い | 答えの方向 |
|------|-----------|
| AWSサービスへの権限管理 | IAM |
| アプリユーザーの認証（ログイン） | Cognito |
| データの暗号化キー管理 | KMS |
| 通信の暗号化（証明書） | ACM |
| Web攻撃（SQLi、XSS）を防ぐ | WAF |
| DDoS対策 | Shield |
| 異常なアクティビティを検知 | GuardDuty |

詳細 → `セキュリティ.md`

---

## 5. 障害に強くするか（可用性・耐障害性）

SAAで最も問われる観点。必ず「どう壊れるか」と「どう生き残るか」をセットで考える。

| 問い | 答えの方向 |
|------|-----------|
| 1台が壊れても動き続ける | マルチAZ構成 |
| 負荷が増えたとき自動で増減 | Auto Scaling |
| 別リージョンに切り替えたい | マルチリージョン + Route53 |
| データを失いたくない | S3バージョニング / RDSスナップショット |
| すぐに復旧したい（RTO低減） | パイロットライト / ウォームスタンバイ |

---

## 6. 速くするか（パフォーマンス）

| 問い | 答えの方向 |
|------|-----------|
| 読み込みを高速化（DB） | ElastiCache / RDSリードレプリカ |
| 読み込みを高速化（静的コンテンツ） | CloudFront |
| データ転送を高速化 | S3 Transfer Acceleration |
| クエリを高速化（DynamoDB） | DAX |

---

## 7. 安くするか（コスト最適化）

| 問い | 答えの方向 |
|------|-----------|
| EC2を安く使いたい（長期・安定） | リザーブドインスタンス |
| EC2を安く使いたい（短期・割り込みOK） | スポットインスタンス |
| S3のデータを段階的に安く | ライフサイクルポリシー + Glacier |
| 使ってないリソースを自動停止 | Lambda + スケジュール |

---

## この地図の使い方

試験問題を読んだとき：
1. 「この問題は上の7項目のどれを問うているか」を特定する
2. 該当のマップファイルを開いて判断基準を確認する
3. 答えを選んだ「理由」を自分の言葉で書き留める

理由を言語化できた問題は、次に同じ問題が出たとき必ず解ける。
