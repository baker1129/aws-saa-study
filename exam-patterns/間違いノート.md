# 間違いノート（exam-patterns）

## このノートの目的

「間違えた問題」を記録するのではなく、**「理由を言えなかった所」と「新しく手に入れた判断の武器」を貯める**場所。
正解・不正解は問わない。正解しても理由が曖昧なら記録する。

SAAの問題は、ほぼ必ず **選択肢ごとに「殺せる条件」が1つずつ仕込まれている**。
だからこのノートの主役は2つ：

1. **殺せる条件** … その選択肢を、問題文のどの言葉で消せるか
2. **手に入れた武器** … 「このキーワード → この判断」というルール

これが溜まるほど、初見の問題でも「あ、これは○○の軸だ」と即座に見抜けるようになる。

## 2026-05-29 ｜ Q3 / S3ストレージクラス（カテゴリ：ストレージ）

**一行で**：要件ごとにS3ストレージクラスを選ぶ。選択肢ごとに別の判断軸が1つずつ仕込まれた典型問題。

**自分の答えと理由（答え合わせ前に書いたもの）**
> 4番。ライフサイクルで段階移動。2番(Glacier Flexible Retrieval)は低遅延でないので除外。「消失リスク最小」の軸は理解が曖昧だった。

**正解**：4番（S3 Standard → 30日後 S3 Standard-IA へライフサイクル移動）

**理由は言えたか**：◎ 2番を自力で除外できた ／ △ 1番を消す軸（消失リスク）が曖昧だった ← 今日の収穫

**選択肢の殺し方（問題文のどの言葉で消すか）**

| 選択肢 | 殺せる条件 | 軸 |
|---|---|---|
| 1. One Zone-IA | 「データ消失リスク最小」→ 単一AZ保存なので消失リスクあり | 耐久性／AZ冗長 |
| 2. Glacier Flexible Retrieval | 「低遅延で取り出す」→ 取り出しに遅延が発生 | 取り出し速度 |
| 3. Standard-IA→Deep Archive | 頻繁アクセスにIAは取り出し料金で非効率＋Deep Archiveは遅い | コスト＋速度 |
| 4. Standard→Standard-IA | 全要件を満たす | ✓ 正解 |

**今日手に入れた武器**
- 「**消失リスク最小／データを失いたくない／耐久性**」→ **One Zone-IAを消す**。One Zoneは単一AZ保存。Standard系（Standard / Standard-IA）は3つ以上のAZに分散保存。
- 逆に「**再生成できる／多少消えてOK／とにかく安く**」→ One Zone-IAを**選ぶ**。
- 「**低遅延／すぐ取り出す**」→ Glacier系（Flexible Retrieval / Deep Archive）を**消す**。

**次に同じ型が出たら**：選択肢を見た瞬間「この選択肢は問題文のどの言葉で死ぬか」を1つずつ言う。正解探しより先に消去。

## 武器の早見表（溜まってきたらここに集約する）

| キーワード（問題文の言葉） | 判断 |
|---|---|
| 消失リスク最小／失いたくない | One Zone-IA を消す（単一AZ） |
